## Problem

Scout does not specify package-manager distribution or appliance-specific installation for Homebrew, WinGet, Scoop, Home Assistant, or Synology NAS.

## Context

Beszel documents these installation paths. This ticket records distribution and lifecycle integration, not the underlying macOS, Windows, or NAS monitoring requirements. Package provenance must retain Scout's signed-release and rollback guarantees.
