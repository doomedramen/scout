## Problem

Scout's roadmap places Windows after macOS but has no Windows agent specification or verified collection, service installation, update, and recovery behavior.

## Context

Beszel documents Windows packaging, drive monitoring, hardware sensors, SMART support, service operation, and upgrades. Scout needs explicit supported versions, Windows service identity, permissions, metrics, signed updates, and platform-specific recovery.
