## Problem

Scout does not specify supported mobile, desktop menu-bar, Home Assistant dashboard, or e-ink dashboard integrations.

## Context

Beszel documents several first-party or community clients and dashboards. Scout already exposes a REST API, but stable integration contracts, authentication scopes, compatibility policy, and ownership of any official client remain undecided.
