## Problem

Scout's roadmap names macOS after Linux but has no macOS agent specification or verified collection, installation, update, and recovery behavior.

## Context

Beszel documents macOS installation and Apple Silicon GPU collection. Scout needs explicit supported versions, host metrics, launch service packaging, permissions, signed update behavior, and unsupported Linux-only capabilities.
